# 💩 Poop Bagel 🥯

A deeply unnecessary web app where you shmear poop on a bagel.

- **🔪 Shmear** — drag across the bagel to spread
- **🌽 Corn bits** — tap to add garnish
- **🪰 Flies** — tap to summon flies
- **💨 Stink** — toggle stink lines
- Hit ~92% coverage for a special prize

Just open `index.html` in a browser. No build, no dependencies, no dignity.
